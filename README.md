# 上海房价等值线分析图

在线分析页面：[打开房价等值线图](https://devide2352720-boop.github.io/house_price_map/)

## 上传房价数据

打开分析页面后，在左侧“导入房价数据”区域点击“选择文件”上传 Excel 文件。页面也提供“下载示例数据表”链接；下载后可直接上传该示例表，生成房价等值线。

Excel 第一张工作表需要包含以下列：

- `项目经度`
- `项目纬度`
- `25-26年成交均价`

示例数据文件：[新房项目级-澜思取数0403 - 副本.xlsx](./新房项目级-澜思取数0403%20-%20副本.xlsx)
